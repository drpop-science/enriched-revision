# 3D Convection V15.5.2 — presentation refinement

V15.5.2 is a classroom-presentation refinement of V15.5.1.

## Main changes

1. **Exam answer is now a solid central white card**
   - much higher contrast;
   - wider and more obviously separate from the simulation;
   - intended as a reading / recall focus;
   - the diagram can be covered deliberately while students read the answer.

2. **Tutorial card is wider and shallower**
   - same successful lower-left position as before;
   - slightly larger text;
   - darker text for laptop readability;
   - reduced visual height and a more banner-like shape.

3. **Tutorial uses a controlled heater position**
   - when Tutorial starts, the heater moves to a standard demonstration position;
   - when Tutorial ends, the heater returns to the user's previous position;
   - this keeps the guided animation consistent each time.

4. **Step 2 equal-volume wireframes are repositioned**
   - warm red wireframe: high in the plume near the surface;
   - cool blue wireframe: high towards the top-right of the water;
   - this improves separation from the tutorial banner and makes the density
     contrast easier to see.

5. **The interaction hint is simplified**
   - replaced with:
     "Grab the heater in the diagram and drag it left or right, or use the
     position slider below."

6. **The heater slider is now view-relative**
   - when the tank is rotated 180°, dragging the slider left still moves the
     heater visually left in the current view;
   - the left/right nudge buttons are also view-relative;
   - direct dragging of the heater remains view-relative as in V15.5.1.

## Physics changes

None.

The solved convection flow, particle model, packing, arrows, trace particles,
temperature colouring and presentation mode are unchanged.
